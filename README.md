# Weatherness
Виджет погоды для SillyTavern. Модель анализирует последние сообщения чата (место, время суток, погоду) и создаёт виджет в стиле iOS/Google-погоды, который появляется до или после текста бота.

## Возможности

1. Два вида: прямоугольный (время, место, погода, градусы) и квадратный (то же + почасовой прогноз на 7 часов, восход/закат)
2. Все полностью настраиваемое: от единиц измерения до положения в чате  
3. Дополнительно (включается в настройках): предупреждение о бурях, фаза луны, сила ветра
Темы: авто (по погоде и времени суток), тёмная, светлая, синяя, розовая, фиолетовая, зелёная, свой цвет. Настройка прозрачности
4. Виджет сохраняется в сообщении и остаётся после перезагрузки чата
5. Кнопки в меню сообщения (⋯): *облачко* - создать/обновить погоду, *ластик* - убрать виджет
6. Русский и английский интерфейс (по умолчанию русский)
7. Работает на ПК и на телефоне
   
## Установка

Extensions → Install extension и вставить ссылку:
[https://github.com/Ayrissa/Weatherness](https://github.com/Ayrissa/Weatherness.git) 

## Настройка
Extensions → Weatherness → API: адрес (например https://openrouter.ai/api/v1), ключ, модель.
Нажмите «Проверить соединение».
Выберите вид, тему и положение виджета; отправьте сообщение боту.

Запросы идут из браузера напрямую. Если сервис блокирует их из-за CORS, используйте API, который это разрешает (OpenAI, OpenRouter, Gemini через OpenAI-совместимый адрес и др.).
